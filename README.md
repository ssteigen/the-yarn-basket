# The Yarn Basket

**A redesigned website for a local knitting supply store**

[🌐 Live Demo](https://ssteigen.github.io/the-yarn-basket/)

## About This Project

This redesign was created as a portfolio project to demonstrate web design and development skills. The original website belonged to The Yarn Basket, a real knitting supply store in Pennsylvania.

## Overview

This is a complete redesign of The Yarn Basket's website, a knitting supply store located in Chambersburg, PA. The project demonstrates modern web design principles applied to a small business website.

## Features

- **Responsive Design**: Mobile-first approach using Foundation CSS framework
- **Project Gallery**: Showcase of customer knitting projects with detailed yarn and pattern information
- **Class Information**: Complete schedule and pricing for knitting classes
- **Contact & Hours**: Essential business information with embedded Google Maps
- **Newsletter Signup**: Email subscription form for customer engagement

## Technical Stack

- **HTML5/CSS3**: Semantic markup with modern CSS custom properties
- **Foundation CSS**: Responsive grid system and components  
- **Google Fonts**: Josefin Sans and Josefin Slab typography
- **JavaScript**: Foundation components and dynamic copyright year
